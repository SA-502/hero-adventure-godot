# مغامرة البطل (Hero Adventure) — Godot 4.7

لعبة منصات كلاسيكية ثنائية الأبعاد (2D Platformer) بأسلوب ماريو الكلاسيكي مع واجهة عربية كاملة، مبنية بمحرك **Godot 4.7.2**.

---

## المزايا الرئيسية
- **فيزياء تحكم دقيقة للاعب (`scripts/player/player.gd`)**: مشي وركض سريع، قفز متغير الارتفاع، مهلة الحافة (`Coyote Time`)، وتخزين ضغطة القفز (`Jump Buffer`)، وحالتا الحجم الصغير والكبير (`SMALL` / `BIG`) مع مناعة مؤقتة بعد الضرر، والانزلاق على سارية العلم.
- **6 عناصر تفاعلية (`scripts/objects/`)**:
  - كتل الاستفهام (`question_block.gd`): عملات، فطر النمو، وفطر الحياة الإضافية `1-UP`.
  - كتل الطوب (`brick_block.gd`): ترتد عند الحجم الصغير وتتحطم بالحجم الكبير (`+50` نقطة).
  - العملات، الفطر، سارية العلم، والمنصات المتحركة.
- **نوعان من الأعداء (`scripts/enemies/`)**: العدو السائر (`walker_enemy.gd`) والعدو الصدفي (`shell_enemy.gd`) القابل للركل والارتداد.
- **3 مراحل متدرجة (`scenes/levels/`)**:
  1. **المرحلة 1-1 (`level_1.tscn`)**: السهول الخضراء والسماء الزرقاء.
  2. **المرحلة 1-2 (`level_2.tscn`)**: أجواء الغروب والفجوات والمنصات المتحركة والسلاحف.
  3. **المرحلة 1-3 (`level_3.tscn`)**: القلعة الليلية والجسور الخشبية والحمم البركانية القاتلة.
- **واجهة وصوتيات عربية متكاملة**: شاشة بداية مع اختيار المراحل وأعلى نتيجة (`best_score`)، شريط معلومات علوي (`HUD`)، قائمة إيقاف مؤقت، شاشة فوز/خسارة، و13 مؤثراً صوتياً وموسيقى خلفية للمراحل.

## المتطلبات والتشغيل
- **المحرك**: Godot **4.7.2** (أو إصدار Godot 4.x متوافق).
- افتح ملف المشروع `project.godot` داخل المحرر واضغط **`F5`** لتشغيل المشهد الرئيسي `res://scenes/main.tscn`.

## مفاتيح التحكم
| الإجراء | المفاتيح |
| :--- | :--- |
| التحرك يمين / يسار | الأسهم أو `A` / `D` |
| القفز | `Space` أو `W` أو السهم العلوي |
| الركض السريع | `Shift` |
| الإيقاف المؤقت | `Esc` أو زر «إيقاف» |
